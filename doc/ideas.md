## 技能树：领悟式解锁（非点数式）

**核心点子**：技能树上的新技能**不靠技能点点出来**，靠"**领悟**"。

**领悟的条件**：
- 树枝上游的前置技能等级 / 熟练度越高，越容易领悟
- 可能要求**多个不同技能**都达到一定熟练度（鼓励多样练）
- 还要靠"**悟性**"和**概率**（参考 D2 的 mf magic find 值——一个独立的运气派生）

**为什么有意思**：
- 代入感：技能不是"开就有"，是"练着练着突然开窍"
- 养成感：每次领悟都是叙事时刻（"我家斥候今天领悟了 X！"）
- 运气：mf 式概率引入横向差异，每个角色领悟顺序不同
- 自然引出"悟性"作为一种属性 / 派生（注意：是否做成 L0 属性需要检验对抗性原则）

**统一吃掉"天赋分支"**：同一技能的质变（DOT 火球 / 爆裂火球 / 追踪火球）**不做独立的天赋系统**，全部走"领悟新技能"。没有 perk 树 / rune 选择那一层。

**技能之间的关系——只有两种**：
1. **技能树**：领悟前置（"练满火球 + 练满集火 → 才有机会领悟灼烧火球"）
2. **协同（synergy）**：参考 **D2 synergy** 模式——技能 A 的等级直接加成技能 B 的某个参数（如"火球每级 +5% 烈焰之墙伤害"）

**没有"形态 / 变体 / rune / mod"概念**。灼烧火球就是灼烧火球，是一个独立技能，和火球的关系**只能是上面两种之一**。不参考 D3 rune 的设计——它把"参数化变种"硬塞"符文"外壳，名实不符、和老家切换那套配合起来更蠢。

**待讨论**：
- "悟性"在 8 维属性框架里的位置（PER 派生？还是独立第 9 维？）
- 领悟与"AI 配置 / 技能配点"如何共存
- 是否所有技能都靠领悟。答：入门技能不需要领悟，其他都靠领悟。
- 概率的合理上下限（既要有惊喜，又不能完全靠脸）
- 同系列变体的组织：火球 → 灼烧 / 爆裂 / 追踪 → 各自再变体 → 指数爆炸。数据 / UI / 心智成本怎么扛？

## 八卦符文系统（占位）

**核心点子**：仿 D2 runeword 的"配方解锁固定效果"模式，但用**八卦**作为基础符号——3 爻二进制结构、对/错/综卦关系、64 重卦组合，天然适合东方武学叙事。

**已钉的原则**：
1. **不进技能层**（避免重蹈 D3 rune 覆辙）。嵌哪里待定（装备 / 心法 / 双轨）。
2. 追求 D2 runeword 的**拼凑配方感**，不要自由叠加。
3. 上限到 **64 卦**为止，不做 384 爻级调味。
4. 优先利用八卦的**天然结构**（爻位 / 对卦 / 错综），不要当 8 个孤立符号。

**待想清楚**：具体嵌入位置、数值规模、和"领悟"系统如何分工、64 卦配方的设计成本。
