# Game Design Document（草案 v0.3）

> 这份文档只描述游戏本身，记录已经确认下来的高层设计结论。

---

## 1. 项目定位

**一句话定位**：

一个俯视斜角的自动战斗刷子游戏（视觉技术路线见 §15）。玩家化身为游戏世界中的主角，通过主角组织队伍、分配装备、派遣多路兵力，在世界地图上持续刷怪、解锁更高价值区域，并把战利品带回基地转化为更强的 build。

**核心灵感来源**：

- 《暗黑 2》：长期刷装备、逐步进入更高价值 farm 区域
- 魔兽地图 / 塔防：观战、编组、分兵、自动执行
- 《三国无双》：战斗过程本身的演出爽感，尤其是命中、死亡表演、群体清场
- 《上古卷轴 5》：主角背景和动机不预写死，由玩家在行动中定义自己

**不是它的东西**：

- 不是强调手操反应的动作游戏
- 不是 Roguelike，不靠每局随机 build 作为主体乐趣
- 不是重剧情 CRPG，不靠大量对话选项建立主角
- 不是重经营模拟，基地服务战斗主循环，不反客为主

---

## 2. 玩家与主角

### 2.1 玩家身份

玩家是**化身型主角**。

但这里的“化身”不是“我按键就是主角的每个动作”，而是：

- 玩家就是这个主角本人
- 玩家代表主角的长期意志、资源分配权和组织权
- 主角可以亲自上阵，也可以让队友独立执行任务

主角的核心不是“必须永远亲临前线”，而是：

- 这支队伍由他组织
- 这批资产归他支配
- 这场行动的后果由他承担

### 2.2 主角形象

- 主角是**沉默型空白主角**
- 背景不预写死
- 初始驱动力不预写死
- 主角和灾变有关，但这种关系不提前写死，交给玩家在游玩中逐渐定义

主角是谁，不主要靠对白成立，而主要靠：

- 战斗风格
- 装备和 build 选择
- 带什么队伍
- 如何分兵
- 如何分配资源

### 2.3 主角的中心性

主角不需要靠战场特权建立存在感。

主角的中心性主要落在**战斗外的长期结构**上：

- 队伍归属主角
- 装备归属主角
- 基地和仓储归属主角
- 世界对玩家的回应，最终都落到主角身上

因此，主角可以在某一场战斗中选择观望、坐镇后方，甚至让队友分路独立作战，而不削弱“玩家就是主角”这件事。

---

## 3. 队伍关系

### 3.1 队友定位

- 队友是**伙伴型**，不是一次性消耗品
- 队友不会轻易永久失去
- 队友可以倒下、重伤、缺席、复活、休整
- 队友的存在感以战斗分工和轻量风味为主，不做大量主导剧情的强人格戏份

### 3.2 主角与队友的关系

- 主角是明确领袖
- 队友整体服从主角
- 队伍关系偏组织、管理、调度，而不是平等旅伴关系
- 队友追随主角的动机是混合的：生存、利益、信服都会存在

### 3.3 队友的自主边界

这个游戏不做复杂的忠诚伦理系统。

高层原则是：

- 队友整体高服从
- 不做复杂反抗、离队、人际撕裂戏
- 错误决策的后果主要体现在战斗失利、恢复成本和资源损耗上

### 3.4 队友成长

- 队友成长路线主要由主角决定
- 队友加入时带有初始职业倾向，但属于**半固定职业**
- 主角可以在合理范围内把他们培养成不同分支

这保证了两点：

- 队伍分工清晰，玩家一眼能看懂阵容
- 新队友加入时，值得重排 build 和编组

## 4. 爽感来源

这个项目依然是“刷子”，但爽感来源不是伤害数字和满地掉落，而是**战斗过程本身**。

### 4.1 核心爽点

- **命中反馈**：重击感、停顿感、音效层次、受击动作
- **死亡表演**：不同敌人的不同死法，Boss 死亡尤其要有场面
- **群体清场**：成片敌人被扫掉，前期紧张、后期收割
- **大招时刻**：可以有长 CD，但长 CD 必须换来明显的高潮段
- **观战满足**：战前配置的队伍和打法真的运转起来

### 4.2 爽感曲线

战斗观感不是固定的，而是随进程变化：

- **前期偏惊险感**：更关注血线、倒地、能不能撑住
- **后期偏收割感**：更关注范围技能、联动、清场速度和画面高潮

这种转变主要依赖：

- 战斗机制升级
- 主角与队伍的 build 成熟
- 技能形态、联动、队伍协作、资源循环逐步完整

### 4.3 明确不依赖的爽点

- 不以伤害数字作为主要反馈来源
- 不以掉落物品在地上乱飞作为主要反馈来源
- 不以 Roguelike 式随机三选一 build 作为主体乐趣

---

## 5. 核心循环

### 5.1 主循环

```text
世界地图上选择区域与兵力投放
  -> 派遣主角和/或队友分路出击
  -> 自动战斗持续刷怪
  -> 打不过则自动返营
  -> 战利品入库
  -> 基地内整理装备、打造、重新编组
  -> 再次派遣
```

### 5.2 节奏特征

这个游戏不强调微循环，而强调中长循环。

玩家的主要乐趣不是连续点击，而是：

- 配置一套队伍
- 看多线战况如何展开
- 把战利品带回基地
- 把成果转成下一轮更强的 build

### 5.3 节奏随进程变化

- **前期**：升级快、调整频繁、短到中回合
- **中期**：build 开始稳定，进入中回合循环
- **后期**：稳定刷高价值区域，低频大调整，偏长线挂机

## 6. 战斗设计

### 6.1 战斗原则

- 玩家不直接手操移动
- 玩家不直接手操普通技能
- 战前定义 build、阵容、编组和策略
- 战中以观察和少量高层介入为主

### 6.2 战斗成长的来源

战斗成长不只是数值变大，更主要来自战斗系统本身的成熟：

- 技能形态更丰富
- 技能之间开始联动
- 队伍协作逐渐成型
- 资源循环能支撑稳定爆发和清场

### 6.3 失败与压力

- 可以有硬直、控制、失败和崩盘
- 失败必须可读
- 玩家能从战况中看懂“为什么输了”

失败的代价以这两层为主：

- **进度受阻**
- **资源损失**

不强调把整段时间或大量积累一次性吐干净。

---

## 7. 世界地图与区域推进

### 7.1 外层结构

游戏采用**世界地图 / 区域推进**结构，而不是纯菜单选图。

这意味着：

- 基地是世界中的后方据点
- 不同区域逐步从未知变成熟悉的 farm 点
- 推进地图的主要目标，是解锁更高价值、更高阶的刷图区

### 7.2 长期目标

世界地图推进的主目标排序是：

1. 解锁更高阶刷图区，进入 end game
2. 推章节 / 清区域
3. 扩大势力范围

也就是说，世界地图本质上是一个**逐步打开高质量 farm 内容的外层结构**。

### 7.3 区域信息

- 区域初见时信息半透明
- 玩家能知道大概风险和产出方向
- **打过一次之后，该区域信息转为公开透明**
- 不做额外的侦察、情报、探子系统

### 7.4 地图结构

- 地图身份固定
- 但每次进入会有小随机，例如怪群组合、波次差异
- 它既适合长期 farm，也保留一点变化

## 8. 多路出兵

### 8.1 核心特征

同一批总兵力可以自由编组。

例如：

- 4 人一路
- 2 + 2
- 1 + 3
- 最多 4 路各自为战

这不是多任务系统，而是**兵力组织方式**。

### 8.2 多路系统的意义

多路出兵的核心不是玩法差异，而是：

- 不同区域难度不同
- 不同区域收益不同
- 不同区域产出材料不同
- 玩家需要决定把有限兵力投到哪里

因此，多路出兵的本质是：

**在多战线下做兵力投资。**

### 8.3 路线的本质

所有路线的核心玩法都还是打怪。

不做这些额外系统：

- 护送
- 采集
- 救援
- 拖延
- 复杂任务脚本

有些区域可能更适合派单人去慢刷材料，但本质仍然是刷怪。

### 8.4 主角与路线

主角可以：

- 亲自带一路
- 去另一条线
- 坐镇后方
- 只负责统筹调度

这保证了：

- 玩家仍然是主角
- 但主角不被固定绑死在某一路

### 8.5 观看方式

多路战线以**总览式观察**为主。玩家像上帝那样，或者说斗蛐蛐但感觉。

玩家更像在看整体战场：

- 哪一路稳住了
- 哪一路崩了
- 哪一路收益更好

而不是只沉浸在单一路线的局部镜头里。

## 9. 派遣规则

### 9.1 默认命令

派遣的**默认行为**非常简单：

- 派去某个区域
- 一直刷
- 玩家手动取消才召回

玩家也可以为每个角色配置 AI（见 §9.4），调整这套默认行为。

### 9.2 默认停止条件

默认 AI 下：

- 不做复杂撤退逻辑
- 不做细致的保命阈值
- **能刷就一直刷，打不过才停**

打不过的判定可以由 AI 配置改写（例如设置血量回家阈值），但默认值就是简单粗暴。

### 9.3 打不过之后

一路打不过时：

- 该路自动停止
- 该路自动回家
- 其他路线不受直接影响，继续刷

这是局部失败，不做跨路线的强耦合连锁。

### 9.4 AI 配置（玩家意志的投射方式）

玩家不直接手操，但仍是主角——通过为主角和队友配置 AI 来表达意志。

这是 §6.1「战中以观察和少量高层介入为主」的具体形式。可调维度大致包括：

- **阈值**：血量回家、逃跑距离、拾取价值线
- **优先级**：精英怪 vs 普通怪、拾取 vs 战斗、自保 vs 救人
- **动作启停**：例如「主角永不主动逃跑」「盗贼禁止主动接战」
- **长期目标**：例如「凑齐 1000 金」「等级达到 30」「刷出某件装备」

设计边界：

- **动作集合是封闭的**——开发者定义 AI 能做哪些事，玩家组合而非编程
- 玩家**不**新增动作、不强制规定动作执行顺序，顺序由 AI 自行规划
- 不调也能玩，默认配置等价于 §9.1 / §9.2 描述的简单行为
- 调与不调是**深度的差别，不是必修内容**

这是把"避免每键操作但仍是主角"这个矛盾的具体解：玩家的中心性体现在 build、装备分配、AI 配置这些**长期决策**上，而不是战时按键。

## 10. 战利品、仓储与装备归属

### 10.1 战利品处理原则

- 战利品不强调满地乱飞
- 回到基地后，**默认先入库**
- 之后玩家再慢慢决定换装、打造、分解、展示

这让战后节奏更顺，不会每次结算都强制打断成装备比较界面。

### 10.2 装备归属

装备本质上归主角所有。

也就是说：

- 战利品先进入主角资产池
- 主角拥有最终分配权
- 队友使用的装备，本质上是主角发下去的军需和赏赐

### 10.3 长期追求

长期留存动力主要有两条：

- 把主角和队伍的 build 拼完整
- 持续追求更高品质的装备

独特装备既是收藏目标，也是 build 核心。装备系统必须服务于 end game 无限刷，因此独特装备不是“拿到即毕业”，而是存在纵向追求维度：

- 词缀 / 数值存在浮动
- 同一件独特装备存在“普通品”和“完美品”
- 玩家的长期目标是凑齐**完美品**，而不仅仅是获得

在这个前提下，后续可以考虑加入**游戏内展示系统**，用于陈列完美品或成套收藏。

## 11. 成长主轴

长期成长主轴的优先级是：

**主角成长 = 装备 / build 成型 > 队伍成长 > 基地成长**

这意味着：

- 玩家最关心的是主角越来越强、build 越来越完整
- 队友主要作为主角打法的延伸和放大器
- 基地是支持主循环的后勤转换器，不是主玩法

### 11.1 主角与装备

主角成长和装备成长是绑在一起的。

玩家长期追求的不是抽象战力，而是：

- 更完整的装备组合
- 更成熟的战斗机制
- 更稳定、更华丽、更高效的清场能力

### 11.2 队伍成长

队伍成长很重要，但主要服务于：

- build 成型
- 多路编组
- 高价值区域 farm

### 11.3 基地成长

基地采用**后勤 + 轻建设**方向：

- 它会逐渐展开功能
- 但不会发展成一套独立经营游戏

---

## 12. 基地定位

基地是一个**会逐渐变好的后勤据点**。

它最重要的功能排序是：

1. 装备与仓储
2. 打造与生产
3. 队伍管理与编组
4. 恢复与复活

这不是说恢复不重要，而是说基地的整体气质更偏：

- 后勤中枢
- 战利品处理中心
- build 转换器

而不是医院或纯生活营地。

---

## 13. 表演感与合理性边界

剧情很少，不是主玩法。这里更强调的是战斗过程的表演感和世界运作的合理性。

表演感主要来自战斗间的过渡节奏，例如：

- 打完一波后的休整
- 生火、吃药、恢复
- 轻量对话
- 再进入下一段战斗

这部分的目的不是推进重剧情，而是让刷怪过程有“段落感”，避免纯数值流水线。

角色与轻叙事的作用主要是：

- 给世界一点温度
- 给战后回营一点呼吸感
- 让队友不是纯数值槽位

但不做这些方向：

- 大量对白分支
- 重关系戏
- 复杂道德系统
- 强剧情伴侣互动

角色存在感主要通过这些东西建立：

- 职业身份
- 战斗表现
- 轻量台词和战后反馈
- 被主角如何配置和使用

### 13.1 合理性原则

本项目追求的“合理”不是绝对写实，而是世界内自洽：系统可以抽象，但不能出戏。

- 便利机制必须有世界内解释
- 强度层级要稳定，普通人不应与主角团同强
- 长距离快速移动极少使用瞬间传送；常规方案应通过马车、商队等方式解释
- 主角团不永久死亡，但倒下必须有真实代价

### 13.2 时间原则

时间不是压力源，而是周转成本。

- 不做持续倒计时逼迫玩家
- 需要代价，但不能让玩家纯等待
- 时间主要服务后勤、恢复、旅行、制造、搬运
- 在多路并行下，时间推进应围绕“有意义事件”进行，而不是机械快进
- 等待期可有轻收益，但不能压过战斗和经营本身

#### 全局单时间线

整个游戏只有**一条全局时间线**。

- 不存在多路之间的时间不同步
- 不存在“单独快进某一路”
- 多路出兵只是多个视角共享同一个时间推进

这和派遣规则的无微操原则一致：既然玩家本来就不干预单路节奏，就不需要为单路提供独立时间控制。

#### 基地操作与时间

玩家在基地整理装备、编组、打造、恢复时，世界时间**默认继续推进**。

- 基地操作不是战斗过程，不存在“换装被怪揍死”这种荒谬情境
- 时间作为周转成本，应该体现在一切需要花时间的动作上，包括玩家自己决策的时间
- 这也鼓励玩家形成稳定 build 后快速派遣，而不是无限比对装备

## 14. End Game

### 14.1 形态

End game 的形态是**无限刷 + 追求极品装备**。

- 不做一次性通关的终局 Boss
- 不做赛季 reset
- 玩家进入 end game 后，长期目标是在已解锁的高价值区域持续 farm，追求更好的装备品质

### 14.2 为什么能撑住无限刷

无限刷要成立，装备系统和数值系统必须为此服务：

- 装备存在词缀浮动和数值浮动
- 极品有清晰的层级：普通极品、完美极品、传说完美品
- 独特装备之间存在 build 联动，留出纵向的组合空间
- 高价值区域之间有产出差异，不同区域刷不同方向的极品

### 14.3 与前期的连续性

End game 不是一个独立模式，而是主循环的自然延伸：

- 核心循环不变，只是区域价值和装备稀有度的天花板打开
- 战斗机制已经成熟，爽感从“惊险”彻底转为“收割”
- 基地功能已经展开完整，专注于极品打造和词缀优化

## 15. 视觉与渲染方向

### 15.1 技术路线

**全 2D 素材 + 3D 空间 + Y 轴 billboard。** 参考《饥荒》（Don't Starve）。

- 所有视觉元素（角色、怪物、植被、建筑、道具、特效）都是 2D sprite
- 世界本身是 3D，地面 / 地形是 3D mesh，单位有真实 (x, y, z) 坐标
- 所有 sprite 以 Y 轴 billboard 方式渲染，永远朝向相机

### 15.2 配套约定

- 阴影使用独立的 blob shadow decal 贴在地面，不依赖 sprite 自身投影
- 角色被树 / 建筑遮挡时遮挡物半透明，避免视野丢失
- 视觉风格走卡通 / 像素 / 手绘方向，不追求写实，靠风格化吸收 sprite 与 3D 世界的视角矛盾

## 16. 关键设计结论

- 玩家是化身型主角，但主角的中心性主要在长期结构，不在战场特权
- 主角是沉默型空白主角，背景和动机不预写死
- 队友是伙伴型，但整体服从主角，成长路线由主角主导
- 游戏主轴是战斗挂机，剧情和经营都只服务主循环
- 爽感主要来自战斗演出、惊险到收割的曲线，以及 build 运转起来的观战满足
- 战斗成长主要靠战斗机制逐步成熟，不只是数值膨胀
- 世界地图推进的主目标是解锁更高价值刷图区
- 多路出兵的本质是兵力投资，不是多任务系统
- 派出去就一直刷，打不过自动回家，其他路线不受直接牵连
- 战利品先入库，装备归主角，主角拥有最终分配权
- 独特装备存在词缀和数值浮动，长期追求是凑齐完美品
- End game 形态是无限刷 + 追极品，装备和数值系统必须为此服务
- 长期成长以主角成长和装备 / build 成型为核心，队伍成长次之，基地最轻
- 整个游戏只有一条全局时间线，不存在多路时间不同步
- 基地操作也消耗时间，时间成本体现在一切世界内动作上
- 时间是周转成本，不是倒计时压力；任何时间成本都不应把玩家锁进纯等待
- 便利机制允许抽象，但必须有世界内解释，避免出戏
- 视觉技术路线为「全 2D 素材 + 3D 空间 + Y 轴 billboard」，参考饥荒
